# Bandhan Function Hall website

A responsive, single-page business website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is required for Google Fonts, hosted photographs and the embedded Google Map.

## WhatsApp
The configured number is `917842379447` (India country code + supplied mobile number).
The floating WhatsApp button and enquiry form open WhatsApp with a pre-filled message.

## Before publishing
- The gallery and main venue visuals now use the three photographs supplied for Bandhan Function Hall, stored in the `assets` folder.
- Confirm venue facilities, capacity, parking, timings and prices before adding them.
- Verify the Google Maps listing URL and business details.
- For a production admin dashboard, database, secure login and online enquiry storage, connect a backend such as Supabase; this starter is a frontend website and does not include an admin backend.
- Deploy the folder to a static host such as Netlify, Vercel or GitHub Pages.
